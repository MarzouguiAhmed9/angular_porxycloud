Le nom de l'événement doit comporter au moins 3 caractères.
La description est requise et ne doit pas dépasser 500 caractères.
La date de début doit être la date actuelle ou après celle-ci.
La date de fin doit être égale ou après la date de début.
Le lieu est requis.
La capacité doit être supérieure à 0.
Le prix doit être supérieur ou égal à 0.
Le statut est requis.
Le type d'événement est requis.
